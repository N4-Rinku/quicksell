An interactive Kanban board built using React.js, fetching data from Quicksell API
. Users can group tickets by Status, User, or Priority, and sort them by Priority (descending) or Title (ascending). The board is responsive, dynamic, and visually appealing, designed for an intuitive project management experience.

Tech Stack: React.js, HTML, CSS, JavaScript, and Bootstrap/Material UI.
Priority Levels: 4 (Urgent), 3 (High), 2 (Medium), 1 (Low), 0 (No Priority).

Deployed easily on Vercel with npm run build for production.

https://quicksell-woad.vercel.app/
